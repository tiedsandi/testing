# 📚 API Versioning + Dokumentasi Swagger di Go Gin

## 🎯 Tujuan Belajar

Setelah belajar ini, lo bisa:
- Design API versioning strategy yang scalable
- Implement URL path versioning di Gin
- Maintain multiple API versions secara bersamaan
- Bedakan breaking vs non-breaking changes
- Implement deprecation headers
- Setup Swagger documentation dengan swaggo/swag
- Pakai annotations untuk auto-generate docs
- Document API endpoints dengan lengkap
- Setup JWT authentication di Swagger UI
- Generate swagger.json untuk Postman
- Setup ReDoc sebagai alternative UI

## 💡 Konsep + Analogi

### API Versioning Strategies

| Strategy | Example | Pros | Cons |
|----------|---------|------|------|
| **URL Path** | `/api/v1/users` | Clear, cacheable | URL changes |
| **Query Param** | `/api/users?v=1` | Same URL | Hidden, hard to route |
| **Header** | `Accept: application/vnd.api+json;version=1` | Clean URL | Not visible, hard to test |
| **Subdomain** | `v1.api.example.com` | Separation | DNS management |

**Rekomendasi:** URL Path versioning → paling straightforward dan common practice

**Analogi Frontend:**
- **API v1** = React 17 → Stable, production-ready
- **API v2** = React 18 → New features, improvements
- **Both running** = Support old & new apps simultaneously
- **Deprecation** = Warning sebelum remove feature (like console.warn)

### Breaking vs Non-Breaking Changes

**Non-Breaking Changes** (Safe):
```json
// v1 response
{"id": "123", "name": "John"}

// v1 + new field (non-breaking)
{"id": "123", "name": "John", "email": "john@example.com"}
```

**Breaking Changes** (Need new version):
```json
// v1 response
{"id": "123", "name": "John"}

// v2 response (breaking: field renamed)
{"id": "123", "full_name": "John"}
```

```go
// internal/v1/user/entity.go
package user

import (
    "time"

    "github.com/google/uuid"
    "gorm.io/gorm"
)

type User struct {
    ID        string         `gorm:"type:char(36);primaryKey" json:"id"`
    Name      string         `gorm:"type:varchar(100);not null" json:"name"`
    Email     string         `gorm:"type:varchar(100);uniqueIndex;not null" json:"email"`
    CreatedAt time.Time      `json:"created_at"`
    UpdatedAt time.Time      `json:"updated_at"`
    DeletedAt gorm.DeletedAt `gorm:"index" json:"-"`
}

func (User) TableName() string {
    return "users"
}

func (u *User) BeforeCreate(tx *gorm.DB) error {
    if u.ID == "" {
        u.ID = uuid.New().String()
    }
    return nil
}

// CreateUserRequest for v1
type CreateUserRequest struct {
    Name  string `json:"name" binding:"required" example:"John Doe"`
    Email string `json:"email" binding:"required,email" example:"john@example.com"`
}

// UpdateUserRequest for v1
type UpdateUserRequest struct {
    Name  string `json:"name" binding:"required" example:"John Doe"`
    Email string `json:"email" binding:"required,email" example:"john@example.com"`
}

// UserResponse for v1

    ID        string    `json:"id" example:"123e4567-e89b-12d3-a456-426614174000"`
    Name      string    `json:"name" example:"John Doe"`

}
```

```go
    service Service

// @Failure      500      {object} map[string]string "error: string"
// @Security     BearerAuth
// @Router       /api/v1/users [get]

    limit := 10

    users, total, err := h.service.GetAll(c.Request.Context(), page, limit)
```

### 5. Deprecation Middleware

```go
// pkg/middleware/deprecation.go
package middleware

import (
    "fmt"
    "time"

    "github.com/gin-gonic/gin"
)

// Deprecate adds deprecation warning headers to response
func Deprecate(version string, sunsetDate time.Time, newVersion string) gin.HandlerFunc {
    return func(c *gin.Context) {
        // Add deprecation headers
        c.Header("Deprecation", "true")
        c.Header("Sunset", sunsetDate.Format(time.RFC1123))
        c.Header("Link", fmt.Sprintf("</api/%s>; rel=\"successor-version\"", newVersion))
        
        // Optional: Add warning header
        warningMsg := fmt.Sprintf(
            "299 - \"API version %s is deprecated and will be removed on %s. Please migrate to %s\"",
            version,
            sunsetDate.Format("2006-01-02"),
            newVersion,
        )
        c.Header("Warning", warningMsg)

        c.Next()
    }
}
```

```go
// cmd/api/main.go
package main

import (
    "log"
    "time"

    "github.com/gin-gonic/gin"
    swaggerFiles "github.com/swaggo/files"
    ginSwagger "github.com/swaggo/gin-swagger"

    // Import generated docs
    _ "your-project/docs"
    
    v1user "your-project/internal/v1/user"
    v2user "your-project/internal/v2/user"
    "your-project/pkg/middleware"
)

// @title           Your API
// @version         2.0
// @description     This is a sample API server with versioning support.
// @termsOfService  http://swagger.io/terms/

// @contact.name   API Support
// @contact.url    http://www.example.com/support
// @contact.email  support@example.com

// @license.name  MIT
// @license.url   https://opensource.org/licenses/MIT

// @host      localhost:3000
// @BasePath  /

// @securityDefinitions.apikey BearerAuth
// @in header
// @name Authorization
// @description Type "Bearer" followed by a space and JWT token.

// @x-extension-openapi {"example": "value on a json format"}

func main() {
    r := gin.Default()

    // CORS
    r.Use(func(c *gin.Context) {
        c.Writer.Header().Set("Access-Control-Allow-Origin", "*")
        c.Writer.Header().Set("Access-Control-Allow-Methods", "GET, POST, PUT, PATCH, DELETE, OPTIONS")
        c.Writer.Header().Set("Access-Control-Allow-Headers", "Content-Type, Authorization")
        
        if c.Request.Method == "OPTIONS" {
            c.AbortWithStatus(204)
            return
        }
        
        c.Next()
    })

    // Health check
    r.GET("/health", func(c *gin.Context) {
        c.JSON(200, gin.H{
            "status":  "ok",
            "version": "2.0",
        })
    })

    // Swagger UI
    r.GET("/swagger/*any", ginSwagger.WrapHandler(swaggerFiles.Handler))

    // API v1 (Deprecated)
    v1 := r.Group("/api/v1")
    v1.Use(middleware.Deprecate("v1", time.Date(2024, 12, 31, 0, 0, 0, 0, time.UTC), "v2"))
    {
        // Setup v1 handlers
        v1UserHandler := v1user.NewHandler(nil) // Inject service
        
        users := v1.Group("/users")
        {
            users.GET("", v1UserHandler.GetAll)
            users.GET("/:id", v1UserHandler.GetByID)
            users.POST("", v1UserHandler.Create)
            users.PUT("/:id", v1UserHandler.Update)
            users.DELETE("/:id", v1UserHandler.Delete)
        }
    }

    // API v2 (Current)
    v2 := r.Group("/api/v2")
    {
        // Setup v2 handlers
        v2UserHandler := v2user.NewHandler(nil) // Inject service
        
        users := v2.Group("/users")
        {
            users.GET("", v2UserHandler.GetAll)
            users.GET("/:id", v2UserHandler.GetByID)
            users.POST("", v2UserHandler.Create)
            users.PATCH("/:id", v2UserHandler.Update)
            users.DELETE("/:id", v2UserHandler.Delete)
        }
    }

    log.Println("Server starting on :3000")
    log.Println("Swagger UI: http://localhost:3000/swagger/index.html")
    r.Run(":3000")
}
```

```makefile
	@grep -E '^[a-zA-Z_-]+:.*?## .*$$' $(MAKEFILE_LIST) | sort | awk 'BEGIN {FS = ":.*?## "}; {printf "\033[36m%-30s\033[0m %s\n", $$1, $$2}'

	go mod download
	go install github.com/swaggo/swag/cmd/swag@latest
```

### 11. Breaking vs Non-Breaking Changes Examples

```go
// examples/changes.go
package examples

// ✅ NON-BREAKING CHANGES

// 1. Adding new optional field
type UserV1 struct {
    ID   string `json:"id"`
    Name string `json:"name"`
}

type UserV1Enhanced struct {
    ID    string `json:"id"`
    Name  string `json:"name"`
    Email string `json:"email,omitempty"` // New optional field
}

// 2. Adding new endpoint
// GET /api/v1/users/:id        (existing)
// GET /api/v1/users/:id/posts  (new - non-breaking)

// 3. Adding new query parameter (optional)
// GET /api/v1/users?page=1              (existing)
// GET /api/v1/users?page=1&sort=name    (new optional param - non-breaking)

// 4. Extending enum values
type Status string

const (
    StatusActive   Status = "active"   // existing
    StatusInactive Status = "inactive" // existing
    StatusPending  Status = "pending"  // new value - non-breaking if client handles unknown values
)

// ❌ BREAKING CHANGES

// 1. Renaming field
type UserV2Breaking struct {
    ID        string `json:"id"`
    FullName  string `json:"full_name"` // Breaking: was "name"
}

// 2. Changing field type
type ProductV1 struct {
    Price string `json:"price"` // "99.99"
}

type ProductV2Breaking struct {
    Price float64 `json:"price"` // 99.99 - Breaking: type changed
}

// 3. Making optional field required
type CreateUserV1 struct {
    Name  string `json:"name"`
    Email string `json:"email,omitempty"` // Optional
}

type CreateUserV2Breaking struct {
    Name  string `json:"name"`
    Email string `json:"email" binding:"required"` // Breaking: now required
}

// 4. Removing field
type OrderV1 struct {
    ID     string `json:"id"`
    Total  float64 `json:"total"`
    Status string `json:"status"`
}

type OrderV2Breaking struct {
    ID    string  `json:"id"`
    Total float64 `json:"total"`
    // Breaking: "status" removed
}

// 5. Changing HTTP method
// v1: PUT  /api/v1/users/:id  (full update)
// v2: PATCH /api/v2/users/:id (partial update) - Breaking if clients expect PUT

// 6. Changing response structure
type ResponseV1 struct {
    Data []User `json:"data"`
}

type ResponseV2Breaking struct {
    Items      []User `json:"items"`       // Breaking: "data" renamed to "items"
    Pagination struct {
        Total int `json:"total"`
    } `json:"pagination"`
}
```

```yaml
# .github/workflows/swagger.yml
name: Generate Swagger Docs

on:
  push:
    branches: [ main, develop ]
  pull_request:
    branches: [ main ]

jobs:
  swagger:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v3
      
      - name: Set up Go
        uses: actions/setup-go@v4
        with:
          go-version: '1.21'
      
      - name: Install swag
        run: go install github.com/swaggo/swag/cmd/swag@latest
      
      - name: Generate Swagger docs
        run: swag init -g cmd/api/main.go -o docs
      
      - name: Check if docs are up to date
        run: |
          if [ -n "$(git status --porcelain)" ]; then
            echo "Swagger docs are not up to date. Run 'make swagger' and commit."
            git diff
            exit 1
          fi
      
      - name: Upload swagger.json
        uses: actions/upload-artifact@v3
        with:
          name: swagger-docs
          path: docs/swagger.json
```

## ❌ Common Mistakes + Fix

### 1. ❌ Lupa run swag init setelah update annotations

```bash
# ❌ SALAH — Update handler tapi lupa generate docs
# Edit handler.go → add new endpoint
go run cmd/api/main.go
# Swagger UI tidak update!
```

```bash
# ✅ BENAR — Always generate docs setelah perubahan
make swagger  # atau swag init
go run cmd/api/main.go
```

### 2. ❌ Swagger annotations format salah

```go
// ❌ SALAH — Missing space atau format salah
// @Success 200 {object}UserResponse  // No space before {
// @Param id path string true User ID   // Missing quotes
// @Router /api/v1/users [get]         // Missing space before [get]
```

```go
// ✅ BENAR — Correct format
// @Success      200  {object}  UserResponse
// @Param        id   path      string  true  "User ID"
// @Router       /api/v1/users [get]
```

### 3. ❌ Tidak specify struct tags untuk examples

```go
// ❌ SALAH — No examples di Swagger UI
type User struct {
    ID    string `json:"id"`
    Name  string `json:"name"`
    Email string `json:"email"`
}
```

```go
// ✅ BENAR — Add example tags
type User struct {
    ID    string `json:"id" example:"123e4567-e89b-12d3-a456-426614174000"`
    Name  string `json:"name" example:"John Doe"`
    Email string `json:"email" example:"john@example.com"`
}
```

### 4. ❌ Breaking changes tanpa bump version

```go
// ❌ SALAH — Breaking change di v1 (breaks existing clients!)
// v1 before: {"name": "John"}
// v1 after:  {"first_name": "John"}  // Field renamed!
```

```go
// ✅ BENAR — Create v2 untuk breaking changes
// v1: {"name": "John"}  // Keep unchanged
// v2: {"first_name": "John"}  // New version
```

### 5. ❌ Tidak kasih deprecation warning

```go
// ❌ SALAH — Langsung matikan v1
r.Group("/api/v1")  // Remove tanpa warning!
```

```go
// ✅ BENAR — Kasih deprecation period
v1 := r.Group("/api/v1")
v1.Use(middleware.Deprecate("v1", sunsetDate, "v2"))
// Run v1 with warnings for 3-6 months before removal
```

### 6. ❌ Security definition di handler level (inefficient)

```go
// ❌ SALAH — Repeat security di semua handler
// @Security BearerAuth
func (h *Handler) GetAll(c *gin.Context) {}

// @Security BearerAuth
func (h *Handler) GetByID(c *gin.Context) {}
// Repetitive!
```

```go
// ✅ BENAR — Define globally di main.go
// @securityDefinitions.apikey BearerAuth
// @in header
// @name Authorization

// Then just reference in handlers
// @Security BearerAuth
```

### 7. ❌ Response schema tidak match actual response

```go
// ❌ SALAH — Annotations tidak match code
// @Success 200 {object} UserResponse
func (h *Handler) GetAll(c *gin.Context) {
    c.JSON(200, gin.H{
        "data":  users,  // Actually returns different structure!
        "total": total,
    })
}
```

```go
// ✅ BENAR — Match annotations dengan actual response
type UserListResponse struct {
    Data  []UserResponse `json:"data"`
    Total int            `json:"total"`
}

// @Success 200 {object} UserListResponse
func (h *Handler) GetAll(c *gin.Context) {
    c.JSON(200, UserListResponse{
        Data:  users,
        Total: total,
    })
}
```

### 8. ❌ Enum di annotations tidak enforce di code

```go
// ❌ SALAH — Swagger shows enum tapi code tidak validate
// @Param category query string false "Category" Enums(electronics,clothing,food)
func (h *Handler) GetAll(c *gin.Context) {
    category := c.Query("category")
    // No validation! Accept any value!
}
```

```go
// ✅ BENAR — Enforce enum validation
var allowedCategories = map[string]bool{
    "electronics": true,
    "clothing":    true,
    "food":        true,
}

func (h *Handler) GetAll(c *gin.Context) {
    category := c.Query("category")
    if category != "" && !allowedCategories[category] {
        c.JSON(400, gin.H{"error": "Invalid category"})
        return
    }
}
```

### 9. ❌ BasePath salah di annotations

```go
// ❌ SALAH — BasePath tidak match actual routes
// @BasePath /api
// But routes use /api/v1 and /api/v2
```

```go
// ✅ BENAR — BasePath should be root, version in route
// @BasePath /
// @Router /api/v1/users [get]
// @Router /api/v2/users [get]
```

### 10. ❌ Tidak setup CORS untuk Swagger UI

```go
// ❌ SALAH — Swagger UI tidak bisa call API (CORS error)
r.GET("/swagger/*any", ginSwagger.WrapHandler(swaggerFiles.Handler))
// No CORS middleware!
```

```go
// ✅ BENAR — Setup CORS
r.Use(cors.Default())
r.GET("/swagger/*any", ginSwagger.WrapHandler(swaggerFiles.Handler))
```
